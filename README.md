## 🤖 How I Work with AI

The bottleneck in software has moved from *writing* code to *deciding what to build and proving it's correct*. I treat AI as a force multiplier, not autopilot — the engineering judgment is still mine.

- **Spec first, then generate** — I define the problem, constraints, and acceptance criteria *before* any code is produced, so AI accelerates the **right** thing instead of shipping the wrong thing faster.
- **Agentic workflows** — I drive agentic coding tools (Claude Code, Cursor, Copilot) to plan multi-step changes, run tests, and iterate across an entire codebase — while staying accountable for intent and outcome.
- **Review AI like a junior's PR** — every generated change is read for correctness, **security** (SQL injection, broken auth, race conditions, unsafe defaults), and fit with the existing architecture before it merges.
- **Context engineering** — I feed models the right context (schemas, API contracts, team conventions) and maintain reusable prompts/rules so output matches our standards on the first pass.
- **Judgment over tool-chasing** — system design, trade-offs, and *"should this even exist?"* stay human calls. AI handles the draft; I own the decision and the quality bar.
